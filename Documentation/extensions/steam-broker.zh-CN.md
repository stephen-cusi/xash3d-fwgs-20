# Steam API Broker 协议规范

## 概述

由于 Steamworks SDK 的专有性质，它无法在 Xash3D FWGS 支持的所有平台上运行，由于 GNU GPLv3 许可证，我们也不能直接链接库。

然而，broker 来了，通过在安装了 Steam 客户端的机器上运行它（最好在受信任的网络中），引擎可以与之通信，获取登录 Steam 保护的多人游戏服务器所需的信息。

## 主要特性

Broker 使用简单的基于 TCP 的二进制协议，具有以下特性：

- 每个连接一个活跃会话：一旦会话激活，broker 将拒绝所有其他 TCP 连接，直到会话终止。
- 所有消息遵循一致的结构，包含头部、长度和有效载荷：这称为"帧"。
- 有状态交互：命令影响会话状态，某些命令仅在特定状态下有效。
- 数字参数以小端格式编码，兼容大多数平台。
---

## 帧格式

所有通信使用固定的帧结构：

| 字段 | 大小 | 类型 | 描述 |
|-------|------|------|-------------|
| Header | 4 字节 | ASCII | 帧起始签名 |
| Length | 2 字节 | uint16_t (LE) | 有效载荷大小（字节） |
| Payload | N 字节 | 二进制 | 命令字符串或响应数据 |

**注意**：
- 头部必须恰好是 `SBRK`（十六进制形式 `53 42 52 4B`）
- 最大帧大小：软限制为 4096 字节，硬限制为 65535 字节（由于使用 uint16_t）

---

## 会话生命周期

```
┌──────────────┐
│     IDLE     │ ← 初始状态，接受新的 TCP 连接
└──────────────┘
       │ sb_gamedir
       ↓
┌──────────────┐
│    ACTIVE    │ ← 会话已建立，拒绝所有其他 TCP 连接
└──────────────┘
       │ sb_connect
       ↓
┌──────────────┐
│    ACTIVE    │ ← 客户端获取认证票据以连接游戏服务器
└──────────────┘
       │ sb_disconnect
       ↓
┌──────────────┐
│     ...      │ ← 客户端宣布从游戏服务器断开，可以再次连接某处
└──────────────┘
       │ 
       ↓
┌──────────────┐
│    ACTIVE    │ ← 客户端关闭游戏，终止 broker 以重置 Steam 客户端状态
└──────────────┘
       │ sb_terminate
       ↓
┌──────────────┐
│  RESTARTING  │
└──────────────┘
```

## 命令

以下所有命令都 meant 从客户端作为帧的有效载荷发送到 broker。Broker 将解析命令字符串并相应响应。

### 会话激活

激活会话并通知游戏启动。

**格式**：`sb_gamedir <gamedir>`

**响应**：无

---

### 认证票据请求

请求游戏服务器的认证票据。

**前提条件**：会话必须处于活跃状态

**格式**：`sb_connect <ip:port> <server_steamid> <secure> <challenge>`

**参数**：

| 名称 | 描述 |
|------|------------------|
| `<ip:port>` | 游戏服务器地址（例如 `127.0.0.1:27015`） |
| `<server_steamid>` | 服务器 SteamID |
| `<secure>` | 0 = 不安全，1 = 安全 |
| `<challenge>` | 用于回复防止的随机值 |


**响应格式**：

| 字段 | 大小 | 类型 | 描述 |
|-------|------|------|-------------|
| Header | 11 字节 | string | `"sb_connect\n"` |
| Challenge | 4 字节 | int32_t (LE) | 请求中 challenge 的回显 |
| SteamID | 8 字节 | uint64_t (LE) | 配置中的客户端 SteamID |
| Size | 4 字节 | uint32_t (LE) | 票据长度（字节） |
| Ticket | N 字节 | - | 认证票据数据 |

---

### 服务器断开通知

通知 broker 从游戏服务器断开。

**前提条件**：会话必须处于活跃状态

**格式**：`sb_disconnect <ip:port> <challenge>`

**响应**：无

---

### 会话终止

通知 broker 游戏关闭并重置 Steam 客户端状态。

**格式**：`sb_terminate`

**响应**：无

---
