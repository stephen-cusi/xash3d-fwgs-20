# XRCON 协议规范

## 概述

XRCON 是一个基于 TCP 的远程控制台协议，在引擎内作为服务器实现。它提供了传统 RCON（通过 UDP 作为带外数据包运行）的替代方案。XRCON 在单个持久 TCP 连接上使用帧化二进制协议，同时最多接受一个客户端。

主要特性：

- 基于 TCP（面向流、可靠）
- 默认端口为 27000
- 最多只有一个并发客户端
- 帧化二进制协议，12 字节头部 + 变长有效载荷



## 配置

XRCON 服务器由两个配置变量控制，均限于特权用户：

| 变量 | 默认值 | 描述 |
|---|---|---|
| `xrcon_enable` | `0`（禁用） | 主开关；启用后，服务器开始监听连接 |
| `xrcon_address` | `127.0.0.1:27000` | 绑定地址和端口；支持 IPv4 和 IPv6。运行时更改此项会触发 XRCON 服务器重启（停止 + 重新绑定） |

默认情况下，XRCON 仅绑定到 localhost（`127.0.0.1`），提供一定程度的访问控制。服务器在显式启用之前不会开始监听。



## 帧格式

所有 XRCON 消息都封装在帧化二进制格式中。每个帧由固定的 12 字节头部后跟变长有效载荷组成。

### 头部（12 字节）

| 偏移 | 大小 | 字段 | 描述 |
|---|---|---|---|
| 0 | 4 | Type | 4 字符消息类型字符串（空字符结尾，在结构中占 5 字节但第 5 字节是填充） |
| 4 | 4 | Version | 协议版本（32 位无符号整数，网络字节序） |
| 8 | 2 | Length | 帧总长度（字节），包括头部（16 位无符号整数，网络字节序） |
| 10 | 2 | Handle | 句柄或序列号（16 位无符号整数，网络字节序；目前始终为零） |


### 协议版本

当前协议版本为 `0x000000D4`（十进制 212）。服务器也接受 `0x00D40000` 以兼容某些第三方客户端（例如 CS2RemoteConsole）。

### 最大帧大小

- 每帧最大有效载荷：4096 字节
- 最大总数据包大小（头部 + 有效载荷）：约 4136 字节
- 接收缓冲区大小：4096 + 64 字节
- 发送缓冲区大小：16384 字节（4 × 最大帧大小）

### 字节序

多字节整数字段（版本、长度、句柄）以**网络字节序**（大端）传输。



## 消息类型

| 类型 | 方向 | 描述 |
|---|---|---|
| `CMND` | 客户端 → 服务器 | 执行控制台命令 |
| `PRNT` | 服务器 → 客户端 | 控制台输出 / 打印消息 |
| `CHAN` | 服务器 → 客户端 | 频道列表（频道元数据） |
| `AINF` | 服务器 → 客户端 | 应用 / 服务器信息 |
| `ADON` | 服务器 → 客户端 | 附加信息 / 服务器名称 |

### CMND — 客户端命令

**方向**：客户端 → 服务器

由客户端发送以在服务器上执行控制台命令。

| 部分 | 大小 | 描述 |
|---|---|---|
| 头部 | 12 字节 | Type = `"CMND"`，version，length，handle |
| 有效载荷 | 变长 | 原始命令字符串（空字符结尾） |

命令字符串被注入引擎的命令缓冲区执行。**没有认证** — 任何连接的客户端都可以执行任意命令。

### PRNT — 服务器打印

**方向**：服务器 → 客户端

由服务器发送以将控制台输出流式传输给连接的客户端。

| 部分 | 大小 | 描述 |
|---|---|---|
| 头部 | 12 字节 | Type = `"PRNT"`，version，length，handle |
| 频道 ID | 4 字节 | 频道标识符（无符号 32 位整数；"控制台"始终为 0） |
| 填充 | 20 字节 | 保留（5 × 32 位无符号整数，全为零） |
| Red | 1 字节 | 红色分量（始终为 255） |
| Green | 1 字节 | 绿色分量（始终为 255） |
| Blue | 1 字节 | 蓝色分量（始终为 255） |
| Alpha | 1 字节 | Alpha / 不透明度分量（始终为 255） |
| Text | 变长 | 控制台输出文本（最多 4096 字节） |


### CHAN — 频道列表

**方向**：服务器 → 客户端

由服务器在初始握手期间（以及可能稍后）发送，用于描述可用的控制台输出频道。

| 部分 | 大小 | 描述 |
|---|---|---|
| 头部 | 12 字节 | Type = `"CHAN"`，version，length，handle |
| 频道数 | 2 字节 | 频道记录数（无符号 16 位整数；始终为 1） |

每个频道记录（58 字节）：

| 字段 | 大小 | 描述 |
|---|---|---|
| 频道 ID | 4 字节 | 唯一频道标识符（无符号 32 位整数；始终为 0） |
| Unknown 1 | 4 字节 | 保留（无符号 32 位整数；始终为 0） |
| Unknown 2 | 4 字节 | 保留（无符号 32 位整数；始终为 0） |
| 默认详细度 | 4 字节 | 默认详细度级别（无符号 32 位整数；始终为 5） |
| 当前详细度 | 4 字节 | 当前详细度级别（无符号 32 位整数；始终为 5） |
| Red | 1 字节 | 频道的红色分量（始终为 255） |
| Green | 1 字节 | 绿色分量（始终为 255） |
| Blue | 1 字节 | 蓝色分量（始终为 255） |
| Alpha | 1 字节 | Alpha 分量（始终为 255） |
| Name | 34 字节 | 频道名称字符串，空字符填充（始终为 `"Console"`） |

此帧的总有效载荷大小：2 + 58 = 60 字节。

### AINF — 应用信息

**方向**：服务器 → 客户端

由服务器在客户端连接后立即发送，在 `ADON` 和 `CHAN` 之前。

| 部分 | 大小 | 描述 |
|---|---|---|
| 头部 | 12 字节 | Type = `"AINF"`，version，length，handle |
| 有效载荷 | 77 字节 | 全零（占位符 / 保留用于结构化应用信息） |

此数据包当前作为占位符，不包含有意义的数据。未来版本可能会扩展它以携带服务器应用的结构化元数据。

### ADON — 附加信息

**方向**：服务器 → 客户端

由服务器在连接握手期间 `AINF` 之后立即发送。

| 部分 | 大小 | 描述 |
|---|---|---|
| 头部 | 12 字节 | Type = `"ADON"`，version，length，handle |
| Unknown | 2 字节 | 保留（无符号 16 位整数；始终为 0） |
| Name Length | 2 字节 | 名称字符串长度（无符号 16 位整数） |
| Name | 变长 | 服务器名称 / 标识符字符串（例如 `"HLDS"`） |

此数据包携带服务器应用名称，即标识服务器类型的短字符串（例如 Half-Life Dedicated Server 的 `"HLDS"`）。



## 安全性

XRCON **没有内置认证或加密**。没有密码验证或传输层安全。任何能建立到 XRCON 端口的 TCP 连接的客户端都对引擎控制台拥有完全的命令执行访问权限。

唯一的安全措施是：

1. **默认 localhost 绑定**：服务器默认绑定到 `127.0.0.1`，仅接受来自本地机器的连接。
2. **默认禁用**：`xrcon_enable` 变量默认为 `0`，因此服务器在显式启用之前不监听。
3. **特权变量**：两个配置变量都限于特权用户，无法通过非特权控制台命令或外部访问修改。



## 与传统 RCON 的比较

| 功能 | XRCON | 传统 RCON |
|---|---|---|
| 传输 | TCP（流） | UDP（数据报、带外） |
| 端口 | 可配置，默认 27000 | 游戏端口（默认 27015） |
| 帧化 | 二进制帧头部 | UDP 上的纯文本 |
| 认证 | 无 | 基于密码 |
| 最大客户端数 | 1 | 多个 |
| 交互格式 | 完整控制台访问 | 仅对提交的命令进行请求-响应 |
| 支持的环境 | 客户端和服务器 | 仅服务器 |
